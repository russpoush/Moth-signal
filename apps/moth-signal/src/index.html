Morse code guide

Short beep or flash = dot (·). Long beep or flash = dash (−). Match each group to a letter below.

A dot lasts 1 beat; a dash lasts 3. Pause 1 beat between symbols and 3 between letters. The lamp and audio carry the same message. A correct answer earns 3 points, or 1 after revealing the written signal. Wrong answers can be retried. Written-only mode (Sound and Flashes off) keeps full points. Flashes start off when your device requests reduced motion.
