# Originality review — November 6, 2026

Two research agents separately reviewed the proposed name and mechanics before feature implementation.

**Finding:** no exact public match was found for the full name **Wingstamp Bureau**, or for the particular combination of independent cycling letter stamps on perches, revisiting a graph to construct a target receipt, and returning to a nest. This supports developing it as a differentiated candidate. It does not prove global originality, patentability, or trademark availability.

## Closest public examples

- [Mosslight Post Office](https://zendenclaws.itch.io/mosslight-post-office): cozy moth postal route planning. The published description does not describe independent cyclic letter stamps.
- [TYPING](https://typing2122.itch.io/typing): movement paths form a word; changing letter state is carried by a rolling die rather than each perch.
- [Letterfall: Word Stamps](https://apps.apple.com/ca/app/letterfall-word-stamps/id6828188640): stamp/word presentation, with falling and rearranged letters rather than revisited graph perches.
- [Parcel Chorus](https://ayyoubaha.itch.io/parcel-chorus): stateful postal routing with linked switches rather than cycling letter receipts.

The common components (word puzzles, routes, postal themes, moths, undo, hints) are established ideas. The evolving per-perch stamps and necessary return visits are this candidate's central distinction.

Full-name searches covered indexed general web, Google Play, Apple App Store, Steam, itch.io, and GitHub. Standalone **Wingstamp** already appears in cosmetics: [Heroka WingStamp](https://www.heroka.nl/collections/alle-producten/products/wingstamp-eyeliner) and [Peach Peach Peach Wingstamps](https://peachpeachpeach.com/). Use the full working title. No comprehensive trademark-register search was performed.

The earlier **Moth Signal** concept did not pass the same screen: close name/theme collision with [Neon Moth Signal](https://play.google.com/store/apps/details?id=com.celestora.neon.moth.signal), moth/Morse precedent [Chitin](https://fuzzyzilla.itch.io/chitin), and existing Morse word-decoding games. This candidate changes the core gameplay; it is not just a rename.
